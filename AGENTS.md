# AGENTS.md

## Como Rodar
1. Certifique-se de que o ambiente virtual está ativado.
2. Execute o comando: `python src/main.py`.

## Como Testar
1. Rode os testes com o comando: `pytest tests/`.

## Pastas Importantes
- `src/`: Contém o código-fonte principal.
- `tests/`: Contém os testes automatizados.

## Regras Obrigatórias
- Mantenha o código formatado com `black`.
- Certifique-se de que todos os testes passam antes de commitar mudanças.
