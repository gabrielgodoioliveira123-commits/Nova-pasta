# Exportação do corpus web do Círculo de Estudos Nous

Esta ramificação contém uma lista explícita de URLs públicas internas, um rastreador que não visita destinos externos e um workflow que gera HTMLs pequenos e ZIPs inferiores a 20 MB.

A exportação remove a antiga seção `Decifra-me ou Lhe Devorarei` quando ela aparece no HTML público, registra falhas de cobertura e não incorpora imagens pesadas.
