# ASTROCORE INFINITY ATOM

## Visão Geral
Este projeto é um sistema Windows modular, seguro e expansível, focado em:
- Manutenção conservadora;
- Diagnóstico e reparo;
- Logs forenses;
- Tarefas agendadas;
- GUI moderna e profissional;
- Build e empacotamento para .exe.

## Estrutura Inicial
A estrutura do projeto será organizada em módulos, com separação clara entre:
- Núcleo de políticas e segurança;
- Motores de limpeza, diagnóstico e reparo;
- Integração com ferramentas externas;
- Interface gráfica (GUI);
- Logs e relatórios;
- Build e empacotamento.
